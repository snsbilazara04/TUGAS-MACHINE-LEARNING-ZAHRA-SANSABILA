# TUGAS-MACHINE-LEARNING-ZAHRA-SANSABILA
DESKRIPSI PRAKTIKUM 
Praktikum ini membahas penerapan Machine Learning untuk melakukan prediksi menggunakan algoritma regresi. Proses pengerjaan dilakukan menggunakan Python dan beberapa library pendukung, seperti Pandas, NumPy, Matplotlib, Seaborn, dan Scikit-learn. Tahapan praktikum dimulai dari membaca dataset, memeriksa kualitas data, membersihkan data, melakukan analisis dan visualisasi, mempersiapkan fitur, membangun model, mengevaluasi hasil prediksi, hingga menyimpan model dan hasil prediksi dalam file. Tujuan praktikum ini adalah memahami bagaimana data diproses sebelum digunakan untuk melatih model Machine Learning serta mengetahui cara membandingkan kinerja beberapa algoritma regresi.
TOOLS DAN LIBRARY 
Beberapa tools dan library yang digunakan dalam praktikum ini adalah:
Python: bahasa pemrograman untuk mengolah data dan membangun model Machine Learning.
Jupyter Notebook: lingkungan kerja interaktif untuk menjalankan kode Python per sel serta menampilkan hasilnya.
Pandas: digunakan untuk membaca, mengolah, dan menganalisis data berbentuk tabel
NumPy: digunakan untuk membantu operasi numerik dan pengolahan array.
Matplotlib: digunakan untuk membuat grafik dan visualisasi data.
Seaborn: digunakan untuk membuat visualisasi statistik, seperti histogram, box plot, dan heatmap.
Scikit-learn: digunakan untuk preprocessing, pembagian dataset, pelatihan model, dan evaluasi hasil prediksi.
Joblib dan Pickle: digunakan untuk menyimpan model agar dapat digunakan kembali.
